# MediCare Connect

A responsive, demo-first healthcare website concept for Pune, Maharashtra. The project is a static HTML, CSS, and JavaScript MVP with no build step or backend dependency.

## Run locally

Open `index.html` in a modern browser. No install or compilation is required.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the files in this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the `/(root)` folder, then save.
5. GitHub Pages will provide the site URL after deployment completes.

## Features

- Responsive landing page and navigation
- Searchable demo doctor directory with specialty, area, consultation type, language, and fee filters
- Demo appointment form with client-side validation and session-only confirmation
- Sample Pune hospital and clinic directory with area filters and directions links
- Sample medicine catalogue, filters, interactive cart, and simulated test-order flow
- Predefined educational health assistant responses with emergency guidance
- Demo sign-in, registration, and patient dashboard interfaces
- Medical disclaimer and clear labels for sample data and simulated services

## Demo and safety notes

This is a student MVP and is not a real healthcare service. Provider profiles, qualifications, fees, appointment slots, hospital listings, product details, prices, and stock are illustrative sample data. No providers or pharmacies are verified. No real appointment is booked, no medicine is dispensed or delivered, and no payment is collected. The assistant uses predefined responses and does not connect to an AI service. Do not enter real personal or health information.

Appointments are retained only in the browser session. There is no database, authentication provider, server, maps integration, prescription upload, or live availability feed configured.

## Before a public healthcare launch

Implement and review secure authentication, server-side authorization, privacy and consent controls, provider and pharmacy verification, prescription workflows, reliable data sources, and applicable Indian healthcare, telemedicine, pharmacy, and data-protection requirements. Do not present demo data as real listings or availability.
